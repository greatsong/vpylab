# 축제길 실험실 — 순수 창작팀

정규 정보 수업을 마친 2인 팀이 8차시에 만든 수준을 가정한 **합성 프로젝트**입니다. 실제 학생의 참여·시간·성취 기록을 대신하지 않습니다. 기존 수업 코드나 공개 프로젝트 코드를 복사하지 않고 이 검증을 위해 새로 설계했습니다.

`main.py`는 완성품, `milestones/01.py`~`08.py`는 기능이 실제로 증가하는 독립 실행 단계입니다. `learning.json`에 8차시의 문제·가설·실험·판단·역할·제안·동료 리뷰·3단계 스캐폴딩·수동 QA 조건을 담았습니다.

1. 참가 인원·출구별 통과 간격을 정합니다.
2. **세 전략 자동 비교**로 집중, 분산, 시차 출발을 같은 조건에서 측정합니다.
3. 완료 시간, 최대 대기, 평균 대기를 함께 읽습니다. **일시정지/계속/처음으로**로 조작할 수 있습니다.
4. 소리는 기본 꺼짐입니다. 켠 뒤 **선택 전략 음형 듣기**를 누르면 반복·교대·넓은 박자의 세 음형을 들을 수 있습니다. 진행과 완료에도 조용한 음이 납니다.

사람 간 충돌·속도 차이·실제 통로 구조를 계산하지 않는 직선 이동 + 선입선출 대기열 모형입니다. 줄의 재배치는 시각화이며, 실제 재난 안전의 예측이나 보장이 아닙니다. 모형 시간은 `dt=0.1`, `rate(30)` 기준 약 3배속입니다.
