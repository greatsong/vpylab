# 대장간: 재사용 오브젝트와 포크 기록 — 2026-11-07

로컬 주소는 `/forge`입니다. 문서·튜토리얼과 독립된 작업대이며 상단 메뉴에서 들어갑니다. 운영 배포는 하지 않았습니다.

## 최종 범위

사용자의 후속 지시를 반영해 **재사용할 단일 오브젝트**만 제작합니다. 지구·달, 태양·지구처럼 여러 천체가 운동하는 시스템은 제외했습니다. 프로젝트로 옮기는 전용 UI와 자동 삽입도 제거하고 **코드 복사**로 단순화했습니다. 필요하면 Python 파일도 내려받을 수 있습니다. 복사 코드와 Python 파일에는 내부 등록 메타데이터를 넣지 않고, 읽기 쉬운 Python과 출처 주석을 제공합니다.

- 캐릭터 8종: 커비·도라에몽·치이카와를 기본 도형으로 단순화한 시작형, 토끼·곰·고양이·펭귄·외눈박이.
- 쓸모 있는 물건 1종: 종.
- 기본 모양 5종: 별·하트·반구/돔·빈 컵·고리.
- 몸통/얼굴/팔다리 조절, 색·표정·장식, 정면/입체/위 시점, 되돌리기/다시 하기, 브라우저 초안 보관.
- 완성된 모양은 compound로 묶고, 생성 함수와 사용 예를 복사합니다. 대장간은 VPyLab 제작 도구이며 생성 함수 자체를 VPython 내장 API라고 표기하지 않습니다.

## 직접 VPython 속성으로 조작

제공 함수가 돌려주는 모듈의 `.object`가 실제 compound입니다.

```python
# 대장간에서 복사한 코드의 my_module이 완제품을 담고 있습니다.
obj = my_module.object
obj.pos.x += 0.1
obj.pos = vector(2, 0, 0)
obj.color = vector(0.5, 1, 0.7)
```

`move_to()`를 쓰지 않아도 됩니다. 직접 pos를 바꾼 뒤 제공 편의 메서드를 쓰더라도 위치가 어긋나지 않도록 compound의 기준점 오프셋에서 현재 위치를 계산합니다. compound 색은 원래 부품 색에 곱해지므로, 원하는 전체 색 변화는 흰 부품에서 가장 분명합니다.

## 종의 세 단계

1. **모양만 만들기**: 너비·높이·색을 조절합니다. 클릭 소리나 이벤트를 등록하지 않습니다.
2. **클릭하면 소리**: 자기 종을 누를 때만 설정한 주파수를 연주합니다. 빈 공간이나 다른 종은 대상이 아닙니다.
3. **음파 효과까지**: 소리와 함께 고리 세 개가 퍼지고 사라집니다. 고리를 매번 새로 생성하지 않고 재사용하며, 효과 중 중복 클릭을 제한합니다. dispose는 효과를 숨기고 이벤트도 해제합니다.

소리와 비동기 이벤트 처리는 VPyLab 확장입니다. 외부 VPython 환경으로 옮길 때 해당 부분의 처리가 필요합니다. 음파 고리는 시각적 표현이며 실제 음향 전파 시뮬레이션을 뜻하지 않습니다.

## 포크와 출처

공개 목록은 생성 코드를 펼쳐 보여 주지 않습니다. **포크해서 가져오기**를 누르면 로그인한 계정에 비공개 파생 프로젝트를 만든 뒤 작업대에서 수정합니다.

- 기존 `vpylab_gallery`의 소유자 RLS와 공개 여부를 사용합니다. 새 DB 마이그레이션은 추가하지 않았습니다.
- 포크 시점에 `remix_from`, 원본 제목·별명 스냅샷, 생성 시각과 비공개 코드가 기록됩니다. 원본은 수정하지 않습니다.
- 다시 공개할 때 내 포크 기록의 소유자와 원본 연결을 먼저 확인하고 같은 기록을 갱신합니다. 다른 사람의 기록을 덮어쓰지 않습니다.
- 직접 참고한 프로젝트의 이름·URL도 추가할 수 있습니다. 이 기록은 모듈 메타데이터, 생성 코드 주석, 다시 공개하는 모듈에 유지됩니다.
- 내 포크와 공개 모듈은 계정에서 다시 조회할 수 있습니다. **단순 ‘내 보관함 등록’과 작업 중 초안은 이 브라우저의 로컬 보관**입니다. 공개 등록과 포크는 별도 계정 작업입니다.
- 공개 내리기는 본인 소유자 조건으로 제한합니다.

공개 목록의 미리보기는 검증된 모양 설정에서 재생성합니다. 공개 글에 들어 있는 임의 Python을 대장간 미리보기에서 실행하지 않습니다. 헤더와 생성 코드가 어긋난 일반 편집 코드는 구조화된 대장간 모듈로 취급하지 않습니다. 코드 숨김은 목록의 표시 방식이며 공개 소스의 접근 권한을 비공개로 바꾸는 기능은 아닙니다.
