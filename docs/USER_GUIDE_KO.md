# VPyLab 사용 안내

서비스의 [사용 안내](https://vpylab.vercel.app/guide)와 함께 보는 학생·교사용 가이드입니다. 기준: 2026-11-07.

## 처음 코딩하는 중·고등학생의 시작 순서

1. **튜토리얼**(`/tutorials`): 빛·소리·클릭 같은 기능을 짧게 체험합니다.
2. **트레이닝**(`/missions`): 기본 문법부터 단계별 코스를 연습합니다.
3. **대장간**(`/forge`): 슬라이더로 재사용할 하나의 오브젝트를 만듭니다.
4. **만들기**(`/sandbox`): 코드를 직접 고쳐 내 작품을 만듭니다.
5. **갤러리**(`/gallery`): 학생 작품과 원본 프로젝트를 보고 아이디어를 나눕니다.

기본 학습은 AI 없이 예상 → 실행 → 수정 → 설명 순서입니다. 상단은 트레이닝 → 만들기 → 튜토리얼 → 대장간 → 갤러리 → 문서 → 사용 안내 순서입니다. 좁은 화면에서는 메뉴를 눌러 같은 순서로 열 수 있습니다. 소개·언어·테마·설정은 더보기에 있습니다.

## 첫 화면의 코드 친구

만두·손전등·공구상자·분홍 친구를 골라 환영 인사를 볼 수 있습니다. 별도 이름은 아직 없습니다. 손 흔들기는 짧게 한 번 재생하고 멈추며, 모션 감소 설정을 따릅니다. 3D를 사용할 수 없으면 정적인 도형 그림을 보여 줍니다.

**이 친구, 내 코드로 만들기**를 누르면 선택한 모양의 VPython 체험을 엽니다. 화면과 Python은 같은 도형 명세를 사용합니다. 색·크기를 바꾸고 손의 회전 각도를 바꾸며 결과를 예상하세요. 구·타원체·상자·원기둥·원뿔·고리·선으로 구성하며 외부 이미지나 AI 호출이 필요하지 않습니다.

## 대장간 사용법

대장간은 문서·튜토리얼과 별도로 사용할 수 있습니다. 다른 프로젝트에서 다시 쓸 **단일 오브젝트**를 제작합니다.

- 캐릭터 8종: 커비·도라에몽·치이카와 연습형, 토끼·곰·고양이·펭귄·외눈박이.
- 종 1종: 모양만 → 클릭하면 소리 → 음파 효과까지.
- 기본 모양 5종: 별·하트·반구/돔·빈 컵·고리.

시작 모양을 고른 뒤 너비·높이·두께, 얼굴과 팔다리, 색·표정·장식을 조절합니다. 되돌리기·다시 하기와 정면·입체·위 시점을 활용하세요. 슬라이더는 생성 코드에 반영됩니다. 실습에서 수정한 Python을 슬라이더로 되돌리지는 않습니다.

이름과 설명을 적고 **내 모듈 보관함에 등록**합니다. 초안과 브라우저 보관함은 해당 브라우저에 저장됩니다. 계정에 기록하는 포크·공개 등록과는 별도입니다.

**완성 모듈 코드 복사** 후 원하는 프로젝트에 붙여 넣으면 충분합니다. 함수의 `pos`와 `scale`을 바꿔 여러 개 만들 수 있고 `.py` 파일로 내려받을 수도 있습니다. 자동 프로젝트 삽입은 없습니다. 생성 함수 이름은 레시피에 따라 달라지므로 복사한 코드의 실제 이름을 사용하세요.

```python
# 복사한 코드 아래의 my_module이 만들어진 모듈입니다.
obj = my_module.object
obj.pos.x += 0.1
obj.pos = vector(2, 0, 0)
obj.color = vector(0.5, 1, 0.7)
obj.opacity = 0.6
```

`move_to()` 대신 일반 VPython `pos` 속성으로 움직일 수 있습니다. `.object`는 실제 compound입니다. 전체 색은 원래 부품 색에 곱해집니다. 흰 부품은 새 색으로 바뀌고 검은 눈은 검게 유지됩니다. 특정 부품만 바꾸려면 생성 함수의 부품 속성을 직접 수정해 보세요.

종은 1단계에서 모양만 만듭니다. 2단계에서 종을 눌러 설정한 주파수의 소리를 듣고, 3단계에서 소리와 함께 퍼지는 고리를 관찰합니다. 고리는 시각 효과이며 물리적인 음향 전파 계산은 아닙니다. 생성 종의 `dispose()`는 이벤트와 효과를 정리합니다.

## 포크와 출처

1. 보관함의 **모두의 모듈**에서 모양을 봅니다. 대장간 목록에서는 코드를 기본으로 펼쳐 보여 주지 않습니다.
2. 로그인 후 **포크해서 가져오기**를 누르면 내 계정에 비공개 파생 기록을 먼저 남깁니다.
3. 작업대에서 수정하고 추가 참고 프로젝트의 이름·링크를 기록합니다(최대 8개).
4. 공개할 별명을 확인하고 **모두의 모듈에 공개 등록**합니다. 같은 포크 기록을 갱신하며 원본 제목·제작자와 참고 기록을 보존합니다.
5. **내 모듈**에서 공개 상태를 확인하고 **내 모듈 공개 내리기**로 비공개로 바꿉니다. 내가 공개한 것은 **내 모듈 이어 만들기**로 수정합니다.

원본이 삭제되어도 이미 기록한 출처 제목·제작자는 보존합니다. 공개 모듈의 코드는 다른 사람이 열고 가져갈 수 있습니다. 목록에서 접어 두는 것은 코드 보안이나 비공개 설정이 아닙니다. 공개 이름·설명에 개인정보를 적지 마세요.

## 캐릭터 튜토리얼

`/tutorials/forge-character`의 세 단계입니다.

1. 기본 도형을 조합하고 compound로 완제품을 만듭니다.
2. 방향키·WASD 또는 화면 버튼으로 완제품을 움직입니다.
3. 아이템을 먹는 조건을 확인하고 조작한 캐릭터의 색만 바꿉니다. 옆 캐릭터와 검은 눈은 유지됩니다.

팀에서는 몸통·표정·움직임·소리를 나누어 실험한 뒤 서로의 코드를 읽고 조합합니다. 한 번에 한 가지 값을 바꾸고 결과를 설명해 보세요.

## 갤러리와 문서

제공된 greatsong21의 두 GlowScript 폴더 원본 33개를 갤러리에 연결했습니다. 학생 작품 7개와 교사·참고 26개를 구분합니다. 참고 목록은 접혀 있으며 펼치면 모두 볼 수 있습니다. 원본 코드 JSON 33개와 썸네일 31개를 함께 제공합니다. 원본 2개는 비어 있어 그대로 보존하며 실행 결과가 있다고 표시하지 않습니다.

각 상세 화면에서 GlowScript 원본과 VPyLab 실습을 열 수 있습니다. 두 실행 환경은 다르므로 모든 원본의 동일한 실행을 보증하지는 않습니다.

문서(`/docs`)에서 **VPython 기본 기능**, **VPyLab 확장**, **제공 함수**를 구분해 표시합니다. 반구·돔 등 도형 가이드는 전체 예제 코드와 바꿔 볼 값을 제공합니다.

- 표준 위치·색·투명도·compound는 VPython 기준입니다.
- 대장간과 생성 편의 함수는 VPyLab 제작 도구입니다.
- 소리 명령과 일부 비동기 이벤트는 VPyLab 확장이므로 외부 VPython으로 옮길 때 조정이 필요합니다.
- 별·하트·컵 등의 압출 모양은 실습에서 지원하지만 공유 HTML의 표현 범위가 더 좁습니다.
- Solar 도형 AI는 학생용 메뉴에 연결하지 않았습니다.

## 팀 프로젝트와 저장

로그인 후 만들기 화면에서 프로젝트를 만들고 초대 코드를 공유합니다. 팀원은 코드로 합류합니다. 움직임·충돌·소리처럼 맡을 부분을 정하고 한 가지씩 실행해 비교합니다.

**코드 저장**은 현재 에디터 코드를 반영하고, **기록 남기기**는 시도·막힌 점·다음 할 일을 적습니다. 팀원이 저장한 뒤 최신 내용을 확인하고 이어 작업하세요. 저장 충돌이 나면 두 버전을 비교해 반영할 내용을 선택합니다. **저장 이력**에서는 이전 버전을 에디터로 복원해 확인할 수 있으며, 반영하려면 다시 저장합니다.

VPyLab 안에서 협력하는 데 GitHub 연결은 필수가 아닙니다. GitHub 저장소에 직접 반영할 팀원에게는 GitHub 공동작업자 권한도 필요합니다. 앱 초대 코드만으로 GitHub 권한이 생기지는 않습니다.
