# VPyLab 사용 안내

서비스의 [사용 안내](https://vpylab.vercel.app/guide)와 함께 보는 학생·교사용 가이드입니다. 기준: 2026-11-07.

## 처음 코딩하는 중·고등학생의 시작 순서

1. **튜토리얼**(`/tutorials`): 빛·소리·클릭 같은 기능을 짧게 체험합니다.
2. **트레이닝**(`/missions`): 기본 문법부터 단계별 코스를 연습합니다.
3. **대장간**(`/forge`): 슬라이더로 재사용할 하나의 오브젝트를 만듭니다.
4. **만들기**(`/sandbox`): 코드를 직접 고쳐 내 작품을 만듭니다.
5. **갤러리**(`/gallery`): 학생 작품과 원본 프로젝트를 보고 아이디어를 나눕니다.

기본 학습은 AI 없이 예상 → 실행 → 수정 → 설명 순서입니다. 상단은 트레이닝 → 만들기 → 튜토리얼 → 대장간 → 갤러리 → 문서 → 사용 안내 순서입니다. 좁은 화면에서는 메뉴를 눌러 같은 순서로 열 수 있습니다. 소개·언어·테마·설정은 더보기에 있습니다.

## 첫 화면의 코드 친구

만두·손전등·공구상자·분홍 친구를 골라 환영 인사를 볼 수 있습니다. 별도 이름은 아직 없습니다. 기본 만들기에서는 각 친구를 하나의 `compound`로 완성합니다. 첫 화면에서는 **만두 빚기 · 불 켜기 · 뚜껑 달그락 · 입 크게 벌리기**를 짧게 재생하고 멈춥니다. **프렌즈**를 고르면 네 친구가 서로 다른 박자로 통통 뜁니다. `friends` 목록 안의 각 `friend.pos`를 바꾸므로 한 친구씩 따로 움직일 수 있습니다. **▶ 버튼**을 누르면 선택한 친구의 전용 변형 모션을 반복하고 **■ 버튼**으로 원래 모양으로 돌아옵니다. 자동 모션은 모션 감소 설정을 따르며, 이 설정이 켜져도 학생이 직접 재생할 수 있습니다. 캐릭터별 색의 3D 스포트라이트와 둥근 무대, 그림자를 제공하며 무대 조명 버튼으로 끌 수 있습니다. 3D를 사용할 수 없으면 정적인 도형 그림을 보여 줍니다.

**이 친구, 내 코드로 만들기**를 누르면 선택한 모양의 VPython 체험을 엽니다. 화면과 Python은 같은 도형 명세를 사용합니다. 색·크기를 바꾸고 완제품의 인사 각도나 프렌즈의 점프 높이·박자를 바꾸며 결과를 예상하세요. 구·타원체·상자·원기둥·원뿔·고리로 구성하며 외부 이미지나 AI 호출이 필요하지 않습니다.

**이 모션, 내 코드로 만들기** 또는 튜토리얼의 **전용 모션**을 고르면 같은 부품의 움직임을 직접 실행합니다. 모션 실습에서는 부품을 따로 둔 채 위치·크기·방향을 바꾸고, 마지막에 `compound`로 합칩니다. 합친 뒤 내부 부품을 다시 변형하는 방식이 아닙니다. 손전등의 빛은 `local_light`와 투명한 원뿔이며 compound에 넣지 않습니다. 소리는 재생하지 않습니다.

## 내 메인 꾸미기와 3D 회전

1. 만들기에서 내 프로젝트를 엽니다. **도구 → 현재 프로젝트를 내 메인으로 설정**을 누르고 작품 이름을 적습니다.
2. 설정하면 홈으로 이동합니다. **내 메인 꾸미기**에서 환영 문구와 배경색을 바꿉니다.
3. **내 작품 실행**을 누르면 실제 Python 코드를 실행합니다. 마우스나 손가락으로 장면을 돌려볼 수 있습니다. 미리보기를 닫거나 다른 화면으로 가면 실행이 종료됩니다.
4. **코드 수정**은 메인에 둔 코드의 사본을 엽니다. 수정한 뒤 같은 도구로 다시 설정하면 메인도 갱신됩니다. 원본 프로젝트 저장과 공개 등록은 별도입니다.
5. **기본 화면으로 돌아가기**는 기본 친구 화면으로 되돌립니다. 작품 사본은 남아 있으며, 다시 꾸미기를 열어 **메인에 이 작품 표시**를 켜면 복구할 수 있습니다.

설정과 코드 사본은 **현재 브라우저에서 계정별로 보관**합니다. 로그인하지 않은 상태는 별도 손님 공간입니다. 다른 기기로 자동 동기화하지 않으며, 브라우저 데이터를 지우면 이 설정도 없어지므로 중요한 원본 코드는 프로젝트에 저장하세요. 메인 설정만으로 작품이 공개되지는 않습니다.

기본 친구 화면도 좌우로 끌어 3D로 돌려볼 수 있습니다. **시점 초기화**로 처음 각도로 돌아옵니다. 터치 화면의 세로 스크롤을 유지하며, 회전은 모션 재생이 끝난 뒤에도 동작합니다.

## AI 없는 자동 완성

편집기의 **자동 완성**을 누르거나 Ctrl+Space를 사용합니다. 입력 중에도 함수 이름, 현재 호출의 인자, 도형·벡터·장면의 속성, 색 이름과 현재 코드의 변수·함수 이름을 제안합니다. 예: `sp` → `sphere`, `sphere(ra` → `radius=`, `ball.` → 도형 속성, `ball.pos.` → `x`·`y`·`z`, `color.` → 색 이름입니다.

↑/↓로 고르고 **Tab으로 적용**, **Esc로 닫기**를 사용합니다. Enter는 평소처럼 줄바꿈합니다. 괄호 안에서는 짧은 인자 안내를 제공하고, 단어에 마우스를 올리면 뜻을 볼 수 있습니다. 주석·문자열에는 전용 제안을 띄우지 않습니다. 프로젝트 코드를 AI나 외부 자동 완성 서버에 보내지 않습니다. 문서와 정해진 규칙으로 돕는 기능이며, 임의의 사용자 함수 반환형까지 추론하는 Python 언어 서버는 아닙니다.

## 코드 속 작은 영어 사전 — VPyLab 학습 안내

중학교 1학년의 눈높이로, `color`·`red`처럼 익숙한 단어는 제외하고 낯선 도형·속성·동작 단어를 안내합니다. **타이핑하거나 자동 완성으로 낯선 단어를 입력하면**, 커서 근처에 그림·뜻·예시가 담긴 작은 카드가 잠깐 나타납니다. 같은 단어의 자동 안내는 계정별로 처음 두 번까지만 제공하고, **알겠어요**를 누르면 즉시 생략합니다. 코드를 가로막거나 입력 초점을 옮기지 않으며 다음 입력·Esc·스크롤로 닫힙니다. 문서와 튜토리얼의 코드 아래에는 접힌 작은 **단어 뜻** 버튼도 있습니다. 필요할 때 직접 열면 코드에 나온 단어 4개를 먼저 보고 나머지는 펼칠 수 있습니다. 문서의 사전은 자동으로 펼치지 않습니다. **알겠어요**를 누른 단어는 이 브라우저의 계정별로 기억해 다음 안내에서 생략하며, 필요하면 **기억한 단어도 보기**로 다시 확인합니다. 단어를 누르면 읽는 법, 짧은 설명, 그림과 예시를 봅니다. 안내는 복사되는 코드나 주석에 들어가지 않습니다.

- `sphere` → 구, 공처럼 둥근 입체
- `radius` → 반지름, 중심에서 가장자리까지
- `opacity` → 불투명도, 0은 투명하고 1은 불투명
- `compound` → 하나로 합치기, 여러 도형을 완제품 하나로
- `pos`·`size`·`vector`·`axis`·`rotate`·`angle`·`rate` 등도 해당 코드에서 안내합니다.

만들기·트레이닝에서는 별도 영어 팁 버튼을 열지 않아도 타이핑하는 단어의 뜻을 처음에만 볼 수 있습니다. 이후 다시 궁금하면 단어에 마우스를 올리거나 문서의 단어 뜻을 열어 확인합니다. 영어 팁은 VPyLab의 학습 안내 UI이며 Python 명령을 추가하거나 코드를 수정하는 기능이 아닙니다.

## 기본 무대 조명 조절 — VPyLab 자체 기능

기본 친구 화면의 **조명 조절**은 처음에는 접혀 있습니다. 펼치면 조명 1·2 각각의 **위치 X/Y/Z, 각도 X/Y/Z, 빛 크기, 밝기, 색상환**을 슬라이더로 조절하고 색상 선택기로 세밀하게 고를 수 있습니다. **기본 조명으로**를 누르면 캐릭터에 어울리는 색과 배치로 돌아옵니다. 조절값은 이 브라우저의 계정별 설정에 저장되며 새로고침하면 패널은 다시 접힙니다. 이 설정은 기본 환영 무대용이며, 내가 둔 프로젝트의 Python 조명은 해당 코드에서 바꿉니다.

## 실행과 소리 정지

**정지**를 누르거나 실행 화면을 닫거나 다른 메뉴로 이동하면 배경음·효과음·개별 음·예약된 음을 함께 멈춥니다. Python 오류나 무응답 실행 종료도 소리를 정리합니다. Python 본문이 정상적으로 끝나도 이미 예약한 음의 길이는 유지하며, 소리가 재생 중이면 **정지**를 계속 사용할 수 있습니다.

## 대장간 사용법

대장간은 문서·튜토리얼과 별도로 사용할 수 있습니다. 다른 프로젝트에서 다시 쓸 **단일 오브젝트**를 제작합니다.

- 캐릭터 8종: 커비·도라에몽·치이카와 연습형, 토끼·곰·고양이·펭귄·외눈박이.
- 종 1종: 모양만 → 클릭하면 소리 → 음파 효과까지.
- 기본 모양 5종: 별·하트·반구/돔·빈 컵·고리.

시작 모양을 고른 뒤 너비·높이·두께, 얼굴과 팔다리, 색·표정·장식을 조절합니다. 되돌리기·다시 하기와 정면·입체·위 시점을 활용하세요. 슬라이더는 생성 코드에 반영됩니다. 실습에서 수정한 Python을 슬라이더로 되돌리지는 않습니다.

이름과 설명을 적고 **내 모듈 보관함에 등록**합니다. 초안과 브라우저 보관함은 해당 브라우저에 저장됩니다. 계정에 기록하는 포크·공개 등록과는 별도입니다.

**완성 모듈 코드 복사** 후 원하는 프로젝트에 붙여 넣으면 충분합니다. 함수의 `pos`와 `scale`을 바꿔 여러 개 만들 수 있고 `.py` 파일로 내려받을 수도 있습니다. 자동 프로젝트 삽입은 없습니다. 생성 함수 이름은 레시피에 따라 달라지므로 복사한 코드의 실제 이름을 사용하세요.

```python
# 복사한 코드 아래의 my_module이 만들어진 모듈입니다.
obj = my_module.object
obj.pos.x += 0.1
obj.pos = vector(2, 0, 0)
obj.color = vector(0.5, 1, 0.7)
obj.opacity = 0.6
```

`move_to()` 대신 일반 VPython `pos` 속성으로 움직일 수 있습니다. `.object`는 실제 compound입니다. 전체 색은 원래 부품 색에 곱해집니다. 흰 부품은 새 색으로 바뀌고 검은 눈은 검게 유지됩니다. 특정 부품만 바꾸려면 생성 함수의 부품 속성을 직접 수정해 보세요.

종은 1단계에서 모양만 만듭니다. 2단계에서 종을 눌러 설정한 주파수의 소리를 듣고, 3단계에서 소리와 함께 퍼지는 고리를 관찰합니다. 고리는 시각 효과이며 물리적인 음향 전파 계산은 아닙니다. 생성 종의 `dispose()`는 이벤트와 효과를 정리합니다.

## 포크와 출처

1. 보관함의 **모두의 모듈**에서 모양을 봅니다. 대장간 목록에서는 코드를 기본으로 펼쳐 보여 주지 않습니다.
2. 로그인 후 **포크해서 가져오기**를 누르면 내 계정에 비공개 파생 기록을 먼저 남깁니다.
3. 작업대에서 수정하고 추가 참고 프로젝트의 이름·링크를 기록합니다(최대 8개).
4. 공개할 별명을 확인하고 **모두의 모듈에 공개 등록**합니다. 같은 포크 기록을 갱신하며 원본 제목·제작자와 참고 기록을 보존합니다.
5. **내 모듈**에서 공개 상태를 확인하고 **내 모듈 공개 내리기**로 비공개로 바꿉니다. 내가 공개한 것은 **내 모듈 이어 만들기**로 수정합니다.

원본이 삭제되어도 이미 기록한 출처 제목·제작자는 보존합니다. 공개 모듈의 코드는 다른 사람이 열고 가져갈 수 있습니다. 목록에서 접어 두는 것은 코드 보안이나 비공개 설정이 아닙니다. 공개 이름·설명에 개인정보를 적지 마세요.

## 캐릭터 튜토리얼

`/tutorials/forge-character`의 세 단계입니다.

1. 기본 도형을 조합하고 compound로 완제품을 만듭니다.
2. 방향키·WASD 또는 화면 버튼으로 완제품을 움직입니다.
3. 아이템을 먹는 조건을 확인하고 조작한 캐릭터의 색만 바꿉니다. 옆 캐릭터와 검은 눈은 유지됩니다.

팀에서는 몸통·표정·움직임·소리를 나누어 실험한 뒤 서로의 코드를 읽고 조합합니다. 한 번에 한 가지 값을 바꾸고 결과를 설명해 보세요.

## 갤러리와 문서

제공된 greatsong21의 두 GlowScript 폴더 원본 33개를 갤러리에 연결했습니다. 학생 작품 7개와 교사·참고 26개를 구분합니다. 참고 목록은 접혀 있으며 펼치면 모두 볼 수 있습니다. 원본 코드 JSON 33개와 썸네일 31개를 함께 제공합니다. 원본 2개는 비어 있어 그대로 보존하며 실행 결과가 있다고 표시하지 않습니다.

각 상세 화면에서 GlowScript 원본과 VPyLab 실습을 열 수 있습니다. 두 실행 환경은 다르므로 모든 원본의 동일한 실행을 보증하지는 않습니다.

문서(`/docs`)에서 **VPython 기본 기능**, **VPyLab 확장**, **제공 함수**를 구분해 표시합니다. 반구·돔 등 도형 가이드는 전체 예제 코드와 바꿔 볼 값을 제공합니다.

- 표준 위치·색·투명도·compound는 VPython 기준입니다.
- 대장간과 생성 편의 함수는 VPyLab 제작 도구입니다.
- 소리 명령과 일부 비동기 이벤트는 VPyLab 확장이므로 외부 VPython으로 옮길 때 조정이 필요합니다.
- 별·하트·컵 등의 압출 모양은 실습에서 지원하지만 공유 HTML의 표현 범위가 더 좁습니다.
- Solar 도형 AI는 학생용 메뉴에 연결하지 않았습니다.

## 팀 프로젝트와 저장

로그인 후 만들기 화면에서 프로젝트를 만들고 초대 코드를 공유합니다. 팀원은 코드로 합류합니다. 움직임·충돌·소리처럼 맡을 부분을 정하고 한 가지씩 실행해 비교합니다.

**코드 저장**은 현재 에디터 코드를 반영하고, **기록 남기기**는 시도·막힌 점·다음 할 일을 적습니다. 팀원이 저장한 뒤 최신 내용을 확인하고 이어 작업하세요. 저장 충돌이 나면 두 버전을 비교해 반영할 내용을 선택합니다. **저장 이력**에서는 이전 버전을 에디터로 복원해 확인할 수 있으며, 반영하려면 다시 저장합니다.

VPyLab 안에서 협력하는 데 GitHub 연결은 필수가 아닙니다. GitHub 저장소에 직접 반영할 팀원에게는 GitHub 공동작업자 권한도 필요합니다. 앱 초대 코드만으로 GitHub 권한이 생기지는 않습니다.

## 영문판과 조명 선택

상단 **더 보기 → 언어 → English**에서 바꾸거나 `/?lang=en` 링크로 바로 영어 화면을 엽니다. 선택은 이 브라우저에 보관합니다. 메뉴·안내·대장간·기초 교재 8차시·저장과 공유 교재 4차시를 영어로 제공하며, 학생의 원래 작품 제목·설명·코드와 GlowScript 원문은 보존합니다. 영어 기초 실습 사본은 `play_note_and_wait("C4", 0.4)`처럼 같은 기능의 영문 명령과 음 이름을 사용합니다. `play_note_and_wait()`는 재생 시간만큼 기다리고 기존 `play_note()`는 바로 다음 줄로 진행합니다. 둘 다 VPyLab 확장으로 문서에 표시합니다. 한국어 별칭도 계속 사용할 수 있습니다. 언어를 바꿔도 편집 중인 코드와 대장간 초안은 유지합니다.

접힌 **조명 조절**을 열면 조명 색을 보여 주는 **조명 1·조명 2 선택 카드**가 나타납니다. 선택한 카드에는 체크가 표시되며, 각 조명의 위치·각도·크기·밝기·색은 따로 유지됩니다. [영문 사용자 가이드](USER_GUIDE_EN.md)도 제공합니다.
