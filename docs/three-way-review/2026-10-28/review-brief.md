# VPyLab local review baseline

This is a local replacement branch for a Python/3D/music education platform. Curriculum originals and old visual design tone are preserved. No deployment is authorized until teacher tests and approves. The supplied files are an explicit allowlist of application source and synthetic tests; no .env, real student data, database, credentials, production logs, other private projects, or real private repository details are included. Dependencies are not installed in this snapshot. Do not run commands that fetch dependencies or contact services. Read/search only; return proposals, do not edit or call agents.

Goals: private drafts preserved per student/window; explicit team checkpoints with optimistic version checks; peer proposals/reviews; GitHub issues, PRs, reviews and commits as evidence of process rather than activity-count grades; teacher private observations and intentional student/team feedback; AI-disabled and AI-optional classes; simple syntax, creative projects, course-code adaptations and public remixes; pleasant musical sound. Project source types currently lesson/mission/example/reference only. Public source URL/SHA/license tracking, review-required class policy, superseding proposal edits, oral evidence types and rich teacher assessment workflow are known incomplete features. Do not present them as implemented. Direct team-save and teacher merge exceptions are currently explicit product choices; stronger course policy is future scope.

Fresh host baseline: 82 backend/GitHub/backup/Python-contract tests + 251 frontend tests passed; original curriculum 5 file hashes unchanged. Previous real private GitHub CLI test succeeded for issue/PR/merge/evidence collection, but there is only one logged-in GitHub user; second-human approval, real App installation/webhook delivery, real Supabase login and classroom load are not verified. No runtime claim from mocks alone. Builds/lint are host checks.

Pre-review fixes in this snapshot: GitHub enqueueProposal requires a same-project exact-code checkpoint ID; external-write guard rechecks checkpoint ID/code/version including old unbound pending jobs; historical valid checkpoint is allowed. Workspace now applies mission codeChecks alongside scene checks (e.g. CT-3 requires function definition and three calls despite a matching scene). Korean sharp/flat names resolve longest prefix first, and chord note strings are normalized to numeric Hz in Python so the HTML export consumer also works. Relevant tests included.
