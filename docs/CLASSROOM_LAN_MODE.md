# 교실 LAN 서버 모드 (교사용 절차)

- 작성일: 2026-10-29
- 명령: `npm run classroom:lan`
- 대상: 학교 외부 회선 없이, 교실 와이파이(LAN)만으로 학생 30명이 VPyLab 미션·예제·샌드박스를 쓰려는 교사

## 1. 구조

Pyodide(Python)는 학생 각자의 브라우저에서 실행됩니다. 교사 맥북은 **파일만 제공**합니다.

| 구성 요소 | 어디서 실행되는가 |
|---|---|
| 앱 화면(React·Monaco·Three.js) | 학생 브라우저 |
| Python 실행(Pyodide WebAssembly) | 학생 브라우저의 Web Worker |
| 앱 파일·Pyodide 핵심 파일(약 14MB)·선택 패키지 | 교사 맥북의 Express 서버(`server/lan/index.js`) |

운영 앱(Vercel)과 다른 점은 다음과 같습니다.

- 로그인(Supabase OAuth)·갤러리·공유 링크·GitHub 저장은 **쓸 수 없습니다.** LAN 주소에서는 OAuth 콜백이 동작하지 않기 때문입니다. 로그인 버튼은 숨겨지고, 저장·공유 요청은 "교실 모드에서는 지원하지 않습니다" 안내로 끝납니다.
- 미션 진행률은 학생 기기의 localStorage에 남습니다. 코드는 편집기의 내려받기 기능으로 파일로 보관하게 안내합니다.
- http 출처이므로 Service Worker 캐시는 쓰지 않습니다. 대신 해시가 붙은 산출물과 `/pyodide/` 파일에 1년 immutable 캐시 헤더를 줘서 같은 기기의 재방문은 브라우저 HTTP 캐시로 처리됩니다.
- 외부 글꼴(Google Fonts·Fontshare) @import를 빌드에서 제거해 인터넷이 없어도 화면이 외부 응답을 기다리지 않습니다. 글꼴은 시스템 글꼴로 대체됩니다.

## 2. 맥북 준비 (처음 한 번, 인터넷 필요)

```bash
cd 10_수업자료/vpylab
npm --prefix client ci
npm --prefix server ci
```

Node.js 22 이상이 필요합니다. 선택 패키지(numpy, matplotlib)를 함께 제공하려면 처음 한 번 인터넷에 연결된 상태에서 아래 명령을 실행해 휠 파일을 내려받습니다. 받은 파일은 `.local/pyodide-packages/`에 남아 다음부터는 다시 받지 않습니다.

```bash
npm run classroom:lan -- --packages numpy,matplotlib --build-only
```

## 3. 수업 당일 실행

맥북을 교실 와이파이에 연결한 뒤 실행합니다.

```bash
npm run classroom:lan -- --skip-build
```

처음 실행이거나 코드를 갱신했다면 `--skip-build` 없이 실행합니다(빌드 약 10초). 선택 패키지를 함께 제공할 때는 `--packages numpy,matplotlib`를 붙입니다(인터넷이 없어도 `.local/` 캐시가 있으면 동작).

터미널에 아래와 같이 접속 주소와 QR 코드가 출력됩니다.

```
[3/3] 교실 서버를 시작했습니다.

  학생 접속 주소: http://172.30.15.219:4077   (en0)
  교사 확인 주소: http://localhost:4077
  (QR 코드)
```

학생은 같은 와이파이에서 QR 코드를 찍거나 주소를 입력해 접속합니다. 종료는 `Ctrl+C`입니다.

### 옵션

| 옵션 | 설명 |
|---|---|
| `--port <번호>` | 기본 4077. 다른 프로그램이 쓰고 있으면 바꿉니다 |
| `--packages a,b` | micropip 패키지를 함께 제공합니다. 의존 패키지와 micropip도 자동 포함됩니다 |
| `--skip-build` | 이미 만든 `client/dist-lan`을 그대로 제공합니다 |
| `--build-only` | 빌드와 패키지 준비만 하고 서버는 띄우지 않습니다 |
| `--no-qr` | QR 코드를 출력하지 않습니다 |

## 4. 방화벽·와이파이 주의점

- **macOS 방화벽**: 시스템 설정 → 네트워크 → 방화벽이 켜져 있으면 처음 실행 때 "node가 들어오는 연결을 허용하겠습니까?" 창이 나옵니다. **허용**을 눌러야 학생이 접속할 수 있습니다.
- **같은 네트워크**: 학생 기기와 맥북이 같은 와이파이(같은 서브넷)에 있어야 합니다. 학교 와이파이가 기기 간 통신(클라이언트 격리, AP isolation)을 막으면 접속이 안 됩니다. 이때는 교사 맥북의 **인터넷 공유**(시스템 설정 → 일반 → 공유 → 인터넷 공유, Wi-Fi로 공유)로 교실 전용 핫스팟을 만들어 쓰는 방법이 있습니다. 보통 30대까지 연결됩니다.
- **주소 확인**: 출력된 주소가 여러 개면 `en0`(와이파이)으로 표시된 주소를 안내합니다. 맥북이 유선과 무선에 모두 연결돼 있으면 학생이 있는 쪽 주소를 씁니다.
- **절전**: 수업 중 맥북 덮개를 닫으면 서버가 멈춥니다. 전원을 연결하고 잠자기를 끄거나 `caffeinate -i npm run classroom:lan -- --skip-build`로 실행합니다.
- **용량**: 핵심 파일만 제공할 때 학생 한 명이 처음 받는 양은 약 20MB(앱 6MB + Pyodide 14MB), numpy·matplotlib까지 함께 제공하면 약 56MB입니다. 와이파이 공유 대역폭을 고려해 처음 접속은 몇 명씩 나누어 하면 안정적입니다.

## 5. 동작 확인 (2026-10-29, 맥북 Chromium에서 LAN 주소로 확인)

http 비보안 출처(`http://172.30.x.x:4077`)에서 다음을 확인했습니다. 결과는 `docs/PYODIDE_LOADING_2026-10-29.md`에 기록했습니다.

- Web Worker 생성과 WebAssembly 컴파일(Pyodide 준비)
- `import numpy` (함께 제공한 패키지를 같은 출처에서 설치)
- Web Audio(`play_note`) 재생 — 실행 버튼 클릭이 사용자 동작으로 인정되어 소리가 납니다
