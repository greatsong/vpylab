# 빛과 소리 대표 콘텐츠와 실습 경험 개선

## 변경

- 기존 튜토리얼에 키보드 우주 악기와 빛나는 아르페지오를 추가했습니다. 완성작 체험 → 한 음 변경 → 자기 작품의 세 단계, 관찰 질문과 친구 시험을 제공합니다. 음량을 낮게 시작하며 작품은 버튼·키 입력에서 연주합니다.
- 정리된 Python Worker는 같은 탭에서 최대 10분 보관합니다. 화면 이탈 때 학생 상태·입력·음원을 정리하고 계정 전환·만료·정리 실패에서는 VM을 폐기합니다. 참고 탭을 볼 때도 보관 기간을 유지합니다.
- Python 준비 중에도 편집기와 안내를 유지합니다. 진행률·재시도는 모바일에서도 표시합니다.
- 시퀀스와 BGM은 AudioContext의 절대 시각으로 짧게 미리 예약하며 정지·음소거는 미래 소스도 정리합니다. 현재 음 표시는 출력 시각을 사용할 수 있으면 보정합니다. 임의 학생 애니메이션 전체의 샘플 수준 동기화를 보장하지 않습니다.
- 장면·카메라가 변하지 않을 때 GPU 그리기를 줄이고, 객체의 캔버스 이동은 출발·도착 화면을 함께 갱신합니다. 2Hz 보정 그리기와 카메라·입력 갱신은 유지합니다.

## 배포 전 검증

현재 운영 main의 커비 개선을 유지한 별도 작업 트리에 이번 변경 26개만 적용했습니다. 전체 클라이언트 85개 파일·879개 검사가 한 번에 통과했고 변경 파일 ESLint·production 빌드가 통과했습니다. 이전 로컬 브라우저에서는 작품의 버튼·키·모바일·음 표시·절대 예약과 정지 장면, 실습 이동·강제 정지·재시도를 검증했습니다.

운영 배포 완료와 운영 브라우저 결과는 실제 배포 이후 별도 증거로 기록합니다. 물리 스피커·Bluetooth·학교 실기기의 전력 사용은 검사하지 않았습니다. 같은 탭의 VM 재사용이며 새 탭·새로고침을 넘어 공유하는 기능은 아닙니다. Python 모듈·가상 파일은 VM 안에 남을 수 있어 새 전역과 완전한 새 VM의 격리를 구분합니다.
