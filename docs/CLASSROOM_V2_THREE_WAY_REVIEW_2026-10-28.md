## Codex의 추가 수정과 선행 안정화

서로 다른 학생이 같은 GitHub 요청을 보내면 기존 제출자의 작업을 일반 성공으로 반환하던 경우를 재현했습니다. **다른 학생·다른 저장본의 재사용은 409와 기존 작업 ID로 알리고, 같은 학생·같은 저장본의 재시도는 기존 작업으로 복구**합니다. 중복 PR을 늘리거나 두 번째 학생에게 실제로 하지 않은 제출을 귀속하지 않습니다.
