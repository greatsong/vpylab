# 첫 화면 변형 모션과 작은 영어 사전 — 2026-11-07

## 모션이 적용되지 않은 것처럼 보이던 이유

첫 화면의 모션은 배포되어 있었으나 2.4초 뒤 기본 모양으로 돌아왔습니다. 프렌즈는 6초였습니다. 또한 `prefers-reduced-motion`이 켜진 환경에서는 자동 실행뿐 아니라 직접 재생 버튼까지 비활성화했습니다. 짧은 자동 모션을 놓치거나 해당 환경을 사용하면 변형을 직접 확인하기 어려웠습니다. 이전 브라우저 검사는 분홍 친구의 짧은 픽셀 변화만 확인해 사용자 입장에서의 이 문제를 잡지 못했습니다.

전용 동작 버튼에 ▶/■와 재생 상태를 표시했습니다. 직접 누르면 선택한 친구의 모션을 반복하고 다시 누르면 원형으로 복구합니다. 친구를 바꾸면 반복 재생을 멈춥니다. 자동 모션 감소를 존중하면서 학생의 명시적 재생은 허용합니다. 카메라 회전·시점 복구·조명 조절과 함께 동작합니다.

만두 주름 모으기, 손전등 발광·빛 원뿔, 공구상자의 경첩 뚜껑·손잡이·걸쇠, 분홍 친구 입·혀 변형과 프렌즈의 바운스를 각각 검사합니다. 캐릭터의 기본 명세와 VPython 모션 실습 코드는 유지했습니다.

## 안내 방식

중학교 1학년 기준으로 낯선 단어만 안내합니다. color/red는 제외합니다. 기본으로 접힌 작은 단어 뜻 버튼만 표시하고 자동으로 펼치거나 팝업을 띄우지 않습니다. 학생이 직접 열었을 때 코드의 단어를 최대 4개 보여 줍니다. 알겠어요를 누르면 계정별 브라우저 설정에 기억해 다음부터 생략하고, 기억한 단어도 보기로 다시 확인합니다. 단어 버튼은 영어와 짧은 한국어 뜻을 표시하고, 누르면 발음 힌트·짧은 설명·그림·예시를 펼칩니다. radius/opacity/sphere/compound는 전용 그림이 있습니다. 복사하는 원본 코드와 주석은 그대로 둡니다.

도형: sphere, box, ellipsoid, cylinder, cone, ring.
속성: radius, opacity, pos, size, vector, length, height, width, thickness, axis, angle, visible, emissive.
동작: rotate, compound, rate.

opacity는 **불투명도**로 0이 투명하고 1이 불투명합니다. VPython의 width는 도형 기본 방향에서 z축 두께로 안내하며 length와 혼동하지 않습니다. emissive는 다른 도형을 비추는 광원이 아니라고 설명합니다.

공유 CodeVocabulary 컴포넌트는 문서 예제·튜토리얼·사용 안내에서 선택해 열 수 있습니다. 편집기에서는 타이핑 또는 자동 완성으로 단어를 입력했을 때 커서 주변에 같은 시각 언어의 TypingWordTip 카드를 보여줍니다. 단어별 자동 표시는 두 번까지만 허용하며 알겠어요로 즉시 중단합니다. 편집기 영어 팁 버튼은 별도로 두지 않습니다. 주석·문자열 속 단어를 제외하고 코드에서 등장한 대상 단어를 골라 설명합니다. 텍스트로 렌더링하고 외부 AI나 네트워크를 사용하지 않습니다. 이 사전은 **VPyLab 학습 안내 UI**이며 VPython API를 바꾸지 않습니다.

## AI 없는 편집기 자동 완성

기존에는 기본 suggest 설정만 있고 VPython용 provider가 없었습니다. 문서 기반 함수·인자, 알려진 도형·벡터·scene·색·리스트의 멤버, 내 변수·함수, Python 기본 이름을 로컬 규칙으로 제안합니다. 코드의 괄호·주석·문자열 문맥을 확인하고, 이미 사용한 인자와 위치 인자를 구별합니다. 타입을 모르는 객체의 멤버는 지어내지 않습니다. Enter는 줄바꿈, Tab은 제안 적용, Esc는 닫기를 유지하며 자동 완성 버튼으로도 열 수 있습니다. hover와 짧은 signature help도 제공합니다.

문서와 규칙만 사용하며 AI 호출·코드 외부 전송이 없습니다. Monaco 공식 [CompletionItemProvider](https://microsoft.github.io/monaco-editor/typedoc/interfaces/editor_editor_api.languages.CompletionItemProvider.html) 인터페이스와 설치 버전의 타입 정의를 확인했습니다. 등록은 인스턴스별 한 번만 수행합니다.
