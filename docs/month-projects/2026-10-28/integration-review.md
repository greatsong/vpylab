# 세 팀 완성 작품 통합 검토

검토일: 2026-10-28. 별도 에이전트가 `month-projects.mjs`, `check-month-browser.mjs`, 갤러리 React/CSS, Vite 설정과 보존된 검증 JSON을 읽었다. 외부 쓰기·새 시험 실행·기존 파일 수정은 하지 않았다.

**현재 실행 결과를 막는 문제나 교사 개인 기록 노출은 발견하지 않았다.** 전달했던 상태 파일 잠금 경합은 root가 수정했고, 변경한 조건을 다시 읽어 해결을 확인했다.

- 외부 쓰기는 고정된 비공개 시험 저장소 `greatsong/vpylab-private-classroom-e2e-20261028`로 제한한다. 실제 두 계정의 숫자 ID·비공개 여부·저장소 ID를 먼저 확인한다. 제안 브랜치만 갱신하며 `force:false`를 요구한다. main 갱신·원격 PR 병합·권한 변경·운영 배포 경로는 없다. 최종 main SHA 보존을 확인한다.
- 인증 토큰은 기존 CLI에서 읽어 메모리에서 사용한다. 공개 갤러리의 검증 JSON에는 프로젝트·Issue·PR·작성자·승인 근거만 들어가며 교사 개인 메모와 학생별 피드백 본문은 포함하지 않는다. DB와 실행 상태는 별도 `.local/month-projects`에 두고 접근 권한을 제한한다.
- API 검증은 학생 간 개별 근거 열람 403, 학생별 피드백과 내보내기의 공개 범위 필터, 다른 팀 Issue/PR 근거의 혼입 방지를 확인한다. 갤러리는 React 텍스트 출력과 파일 다운로드를 사용하며 외부 데이터를 HTML로 삽입하지 않는다. 로컬 교실의 역할 선택은 합성 계정을 위한 시험 기능이다.
- 프로젝트 파일은 `import.meta.url` 기준으로 찾는다. 갤러리의 결과물·중간 코드·학습 설계는 저장소 안의 상대 경로를 사용한다. Vite/백엔드는 루프백에 연결하며 운영 빌드와 산출물 폴더를 구분한다.
- 브라우저 검증은 새 Chromium 컨텍스트에서 실제 Pyodide·WebGL과 WebAudio 상태를 확인한다. 음악을 사람이 청취한 결과라고 주장하지 않는다. 페이지와 GitHub 기록은 합성 프로젝트임을 표시한다.

읽은 검증 결과에서 세 팀의 8차시 발전 기록, 다른 계정의 승인 SHA 일치, 피드백 보호 통과를 확인했다. 수업 코드 활용·리믹스 브라우저 검사는 페이지 오류와 실패가 없었으며 순수 창작은 별도 브라우저 검증 결과를 보존한다. 이후 root의 최종 읽기 재검증에서 표시 QA까지 포함한 창작 10커밋·수업 활용 8커밋·리믹스 8커밋의 로컬 완성 코드·PR head·다른 계정의 최신 승인 SHA 일치를 확인했다. 최종 기록은 `github-verification.json`에 보존한다. 전체 커밋 수를 차시 수로 해석하지 않는다.

## 전달한 수정 사항

**해결 확인:** `month-projects.mjs`의 마지막 catch가 `if (state && lock !== undefined)`인 경우에만 실패 상태를 저장한다. 잠금 취득에 실패한 두 번째 프로세스가 기존 `state.json`을 덮어쓰지 않도록 수정한 코드를 확인했다.

검토 범위는 코드와 보존된 검증 결과이다. 실제 학생의 학습 성취·수업 기간·모든 기기 성능을 입증하지 않는다.

이식성 권고도 반영했다. `check-month-original.mjs`는 개인 홈 캐시 고정 fallback을 제거하고 공통 `VPYLAB_PLAYWRIGHT_MODULE` 설정 또는 일반 `playwright` 모듈 탐색을 사용한다.
