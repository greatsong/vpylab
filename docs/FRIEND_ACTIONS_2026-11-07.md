# 환영 친구 전용 모션 — 2026-11-07

첫 화면의 선택·재생 동작을 캐릭터별로 바꿨습니다.

- 만두: 머리 주름이 중앙으로 모이며 작고 둥근 만두 꼭지가 됩니다.
- 손전등: 렌즈가 밝아지고 실제 PointLight와 3D 빛기둥이 켜집니다. 무대 조명과 별개인 캐릭터 기능입니다.
- 공구상자: 뚜껑·손잡이·잠금장치가 뒤쪽 경첩을 기준으로 함께 달그락 움직입니다. 요청한 시각 모션이며 소리는 넣지 않았습니다.
- 분홍 친구: 입이 부드럽게 커지며 혀도 비례해 움직입니다. 입 윤곽이 몸에 묻혀 깨지지 않도록 앞쪽 위치를 함께 보정했습니다.
- 프렌즈: 서로 다른 박자로 통통 뛰면서 각자 전용 모션을 재생합니다. 시작·끝에 높이와 진폭을 줄이며 정지합니다.

개별 모션은 2.4초, 프렌즈는 6초 후 멈춥니다. 버튼으로 다시 재생하며, 모션 감소 설정과 WebGL 불가 시 정지 화면을 유지합니다. 매 프레임 원래 부품 명세에서 변형을 계산해 재생을 반복해도 누적되지 않습니다. 렌더링 중 새 도형을 만들지 않고, 손전등 빛기둥·빛 자원은 정리 시 해제합니다.

## 실습 및 compound 기준

기존 완제품 만들기는 `make_*()`가 하나의 compound를 반환하며 그대로 유지했습니다. **이 모션, 내 코드로 만들기** 또는 튜토리얼의 **전용 모션** 선택으로 각 친구/프렌즈의 전체 Python 코드에 들어갑니다.

모션 실습은 개별 부품 상태에서 `.pos`, `.size`, `.axis`, `.up`으로 움직이고 마지막에 compound로 완성합니다. 완성 후에는 `friend.pos`로 전체를 이동합니다. 표준 VPython compound의 소모된 내부 부품을 수정하는 예제로 가르치지 않습니다. 근거: [공식 compound 문서](https://www.glowscript.org/docs/VPythonDocs/compound.html). 손전등의 빛은 표준 `local_light`와 투명한 `cone`이며 compound에 넣지 않습니다. AI 호출은 없습니다.

모션 예제 경로: `/tutorials/welcome-friend?step=dumpling-motion`, `flashlight-motion`, `toolbox-motion`, `kirby-motion`, `friends-motion`. 기본 만들기와 전용 모션 사이를 같은 화면에서 바꾸며 최상위 메뉴를 추가하지 않았습니다.

## Claude 검토 반영

읽기 전용 Claude 검토는 첫 180초 제한 이후 같은 사본으로 300초 재시도하여 응답을 받았습니다. 코드 실행은 하지 않았고, P1 없음·P2 네 항목을 제시했습니다. [원문](collaboration/actions-claude-2026-11-07.json).

| 프렌즈 모션 실습에 통통 뛰기 누락 | 검토 대기 중 이미 보완. 각 부품·beam·lamp에 같은 높이를 적용하고 끝에는 원위치. 중간 프레임의 네 위상·높이와 완제품 위치 비교 검사 추가 |
| 실제 손전등 빛의 영향이 약함 | 광원 위치를 렌즈 앞쪽 z=.55로 옮기고, 홈 PointLight 범위 5·강도 4로 조정. PointLight 활성화·정지 및 실제 Python local_light의 색·빔 투명도 검사 |
