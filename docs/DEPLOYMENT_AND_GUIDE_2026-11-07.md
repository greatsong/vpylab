## Claude 지적과 수정

두 차례 검토에서 P0/P1은 발견되지 않았습니다. 이는 읽은 범위에 대한 정적 판단이며 실제 실행 검증은 Codex가 수행했습니다. 검토 원문은 `docs/collaboration/forge-predeploy-claude*.json`에 보관했습니다.

| 지적 | 반영한 수정 |
| --- | --- |
| 원본 삭제 후 포크 재공개가 FK 오류로 막힘 | DB의 null FK와 제목·제작자 스냅샷을 대조하고, 삭제된 연결은 null로 유지하며 출처 보존 |
| 참고 링크 8개를 허용하지만 긴 헤더를 목록에서 제외 | 96KB 파싱 한도와 base64 한도 일치, 게시·포크 전 왕복 검증 |
| 종을 울린 뒤 슬라이더·재마운트가 음파 재생 | 처리한 tick 기록, 마운트 시 현재 tick으로 시작 |
| 내 모듈의 공개 상태·공개 내리기 오류 | 실제 is_public 반영, 게시 행 ID 사용, 계정 목록 상태 갱신 |
| 내 공개 모듈을 다시 포크함 | 공개 목록과 내 계정 목록 구분, 내 목록은 같은 모듈 이어 편집 |
| 로그인 전 오래된 초안이 최신 작업을 가림 | 최신 게스트 초안 우선, 내용 비교로 가져오기 제공 |
| 수정한 로컬 모듈이 옛 계정본에 가림 | 로컬 내용을 우선하며 계정의 공개 상태·소유자·별명만 병합 |
| 포크 후 원작자 별명으로 공개될 수 있음 | 포크하는 사람의 공개 별명 유지 |
| 길이 경계의 공백·이모지 제목이 재파싱 실패 | 코드포인트 단위 자르기와 자른 뒤 trim, 회귀 검사 |
| 빈 게시 응답·갱신 ID 불일치 | 성공으로 반환하지 않고 현재 작업 유지 |
| 공개 JSON/PNG 누락이 SPA HTML 200으로 가려질 수 있음 | projects 경로를 SPA 폴백에서 제외, 운영의 33 JSON·31 이미지 형식과 내용 검사 |

코드의 기본 비노출은 대장간 목록의 UI 동작입니다. 공개 모듈은 오픈소스 재사용 대상이며 갤러리 상세나 공개 실행 경로에서 코드를 읽을 수 있습니다. 이를 비밀 코드 보관으로 설명하지 않았습니다.

## 검증 결과

- 클라이언트: 69개 파일, **785개 테스트 통과**.
- 서버·교실·저장·백업: **158개 테스트 통과**.
- API OG/검증 증거 유틸: **4개 테스트 통과**.
- 린트: 오류 0. 기존 LoadingScreen 의존성 경고 1건 유지.
- 운영 빌드 통과. 번들 크기 경고는 기존 Monaco 번들을 포함합니다.
- 대장간 실제 브라우저: **37개 시나리오 통과**. WebGL 픽셀·14종 시작형·슬라이더 메모리·되돌리기·복사·Pyodide 실행·종 클릭/음파·개별 색·초안·포크/재공개/공개 내리기 포함.
- 운영 웹: **13개 시나리오 통과**, 페이지 오류 0. 원본 33개 링크와 JSON, 썸네일 31개, 도형 문서, 복사 코드 실행, HTML 다운로드, 캐릭터 아이템 획득을 확인했습니다.
- 운영에서 내려받은 실제 HTML: 카메라 위치·중심·축 읽기/쓰기, compound 색·투명도·재질, 화면 크기 변경, cylinder/cone 기준점 검증 통과.
- 커밋 전 gitleaks 비밀정보 검사 통과. 새 키·환경 파일·학생 비공개 자료를 커밋하거나 Claude에 보내지 않았습니다.

운영 HTML 검사는 내보낸 결과물의 코드를 사용하되 Three.js/Pyodide CDN 응답을 동일 버전의 로컬 설치 파일로 대체했습니다. 외부 CDN 가용성 검사는 이 결과에 포함하지 않습니다.

실제 OAuth 로그인과 계정 DB 쓰기는 수행하지 않았습니다. 포크·재공개·공개 내리기는 합성 인증 상태와 가로챈 DB 응답으로 검증했고 라이브 쓰기는 0건입니다. 이 결과만으로 실제 계정의 OAuth·RLS 쓰기 흐름까지 검증됐다고 주장하지 않습니다. 공개 익명 읽기와 배포 웹의 렌더링은 실제 네트워크로 확인했습니다.

Solar 도형 AI는 학생 메뉴에 연결하지 않았습니다. 소리 명령은 VPyLab 확장이며, 압출 도형의 공유 HTML 표현 범위는 실습보다 좁습니다. 제공된 빈 원본 2개를 포함해 모든 GlowScript 원본의 동등 실행을 보장하지 않습니다.
