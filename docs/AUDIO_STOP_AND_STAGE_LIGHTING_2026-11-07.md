# 소리 종료와 접히는 무대 조명 — 2026-11-07

## 소리가 남던 원인

1. 정지 경로가 배경음만 멈춰 개별 음·시퀀스·효과음의 Web Audio 노드와 예약 타이머가 남았습니다.
2. Python Worker 종료와 메인 스레드의 Web Audio 종료는 별개였습니다.
3. 정지 직후 도착한 이전 Worker 묶음이 소리를 다시 예약할 수 있었습니다.
4. Python 본문이 정상 종료하면 실행 상태가 ready로 바뀌어, 길게 예약한 소리가 남아도 정지 버튼이 사라졌습니다.

기존 운영 버전에서 실제 Pyodide로 긴 음·시퀀스·배경음을 재생하고 정지를 눌렀습니다. 최종 출력에 삽입한 AnalyserNode의 RMS는 정지 전 0.05254, 300ms 뒤 0.12698, 2.6초 뒤 0.01162로, 소리가 남는 원인을 재현했습니다. 헤드리스 스피커는 음소거하고 실제 Web Audio 그래프의 신호를 측정했으며 물리 스피커 청취 결과로 주장하지 않습니다.

## 수정

- singleton의 softStop·hardStop·Worker 실패·Python 오류에서 stopAllSounds를 호출합니다. 이 함수는 소리 세대를 올리고 예약 타이머와 배경음을 취소하며 활성 음원을 짧게 감쇠 후 정리합니다.
- 정지 후 들어온 sound 명령과 클릭/위젯 이벤트를 차단하고, 새 실행이 시작될 때만 허용합니다. runId와 Worker 식별 검증도 유지합니다.
- 화면이 사라진 뒤의 오래된 실행 콜백을 막고, Sandbox의 대기 중 실행 RAF도 취소합니다.
- 홈 작품·갤러리·임베드·트레이닝·만들기는 오디오 상태를 구독해 Python 본문 종료 뒤에도 소리가 재생 중이면 정지를 제공합니다.
- 정상 본문 종료와 사용자의 정지를 구별해 홈·갤러리·임베드에서 의도한 예약음을 잘라내지 않습니다. 오류·닫기·화면 이동·명시적 정지는 전부 정리합니다.

## 무대 조명 — VPyLab 자체 UI

기본 친구의 3D 무대 조명에 접힌 details 패널을 제공합니다. 조명 1/2 각각 위치 XYZ, 회전 XYZ(도), 빛 크기·밝기·색상환 슬라이더와 색상 선택기를 사용합니다. 위치·방향·빛 원뿔·스포트라이트·발광부가 함께 바뀌고, 밝기 0이면 가시 광선도 꺼집니다. 슬라이더 이동마다 geometry를 새로 만들지 않습니다. 캐릭터별 기본 색으로 복구할 수 있습니다.

브라우저의 계정별 내 메인 설정에 저장하며 다시 열면 조절 패널은 접힙니다. 개인 프로젝트의 Python 조명 설정을 덮어쓰지 않습니다. VPython API가 추가된 기능이 아닌 VPyLab 홈 UI 기능입니다.

## 검증

- 클라이언트 76개 파일, 819개 검사 통과. 린트 오류 0개(기존 LoadingScreen 경고 1개), 빌드 성공.
- 실제 Web Audio + Pyodide: 명시적 정지, 본문 종료 후 예약음 정지, 화면 이동, Python 오류, 협조하지 않는 무한 루프, 만들기 정지 등 6가지 로컬 시나리오 통과. 정지 300ms와 2.6초 후 RMS < 0.00001 확인.
- 가상 시간 2분을 진행해 예약음·배경음이 다시 살아나지 않는 검사 추가. 실제 교실 런타임 오디오 노드 정리 검사도 통과.
- 실제 WebGL과 입력 이벤트: 기본 접힘·위치/각도/크기/밝기/색 반영·새로고침 보관·모바일·기본 복구 5개 통과.
- 기본 환영 화면 기존 브라우저 검사 17개와 개인 메인 브라우저 검사 14개 통과. 계정 분리는 단위 검사이며 실제 계정 로그인 검사로 주장하지 않습니다.

## 배포 후 두 모델 검토로 확인한 추가 누락

Claude: 트레이닝 기본 툴바의 본문 종료 후 정지, 트레이닝·채점·갤러리 재실행 전 이전 예약음 정리를 채택했습니다. Gemini 4 Argon: 극장 모드 시작의 남은 pendingPlay가 본문 종료 후 코드를 중복 실행하는 문제, 극장의 오디오 정지 버튼, Worker 내부의 정지 후 남은 이벤트 큐/핸들러 정리, 코드 소스 교체 시 이전 실행 정리, 조명 변경 시 숨긴 환영 문구·배경 보존을 채택했습니다. 직접 수정하고 실제 런타임 검증을 추가합니다.

극장 시작도 공통 startProgram 경로로 통합해 대기 코드를 한 번만 소비합니다. 엔진이 아직 준비 상태가 아니면 중단 확인 뒤 대기 코드를 실행합니다. 정상 본문 종료 뒤 오디오가 남으면 극장에서도 정지할 수 있습니다.

기본 화면 복구 시 코드·문구·배경은 보관하고 조명은 기본값으로 되돌립니다. 이후 조명 슬라이더는 lights만 저장해 보관 문구·배경을 지우거나 숨긴 작품을 다시 켜지 않습니다.
