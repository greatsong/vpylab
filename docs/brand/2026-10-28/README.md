# VPyLab 로고·파비콘 · 첫 시안

2026-10-28 · `codex/classroom-v2` · 로컬 적용

서로 다른 두 경로가 하나의 V로 만나는 형태입니다. 파랑을 기본으로 쓰고 청록색 면과 원근감을 더해 3D 실험·창작·협력을 표현했습니다. 기존 화면의 사각형 UI와 색상은 유지했습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `brand/vpylab-logo.svg` | 기본 가로 로고. 밝은 배경 |
| `brand/vpylab-logo-inverse.svg` | 밝은 역상 가로 로고. 어두운 배경·파란 배경 |
| `brand/vpylab-logo-mono.svg` | 단색 인쇄·각인 |
| `brand/vpylab-mark.svg` | 컬러 심벌 |
| `brand/vpylab-mark-inverse.svg` | 역상 심벌 |
| `brand/vpylab-mark-mono.svg` | 단색 심벌 |
| `brand/vpylab-wordmark.svg` | 글자만 있는 벡터 원본 |
| `brand/*.png` | 투명 배경 PNG. 가로 로고 712×192, 심벌 512×512 |
| `favicon.svg` | 브라우저용 벡터 파비콘 |
| `favicon.ico` | 16·32·48px를 포함한 호환용 아이콘 |
| `favicon-32.png` | 32px PNG 파비콘 |
| `apple-touch-icon.png` | 180px 불투명 배경 터치 아이콘 |
| `icon-192.png`, `icon-512.png` | 큰 크기 아이콘 내보내기 |

저장소에서는 `client/public/` 아래에 있습니다. ZIP에는 같은 `brand/` 경로와 아이콘 파일, 이 안내, 시안 이미지가 들어 있습니다. 폰트 원본 파일은 포함하지 않았습니다.

## 사용

- 로고 주변에 심벌 높이의 1/4 이상 여백을 둡니다. 비율을 고정하고 색상별 면을 따로 변형하지 않습니다.
- 글자까지 넣은 가로 로고가 90px보다 작아지면 심벌만 사용하는 편이 읽기 좋습니다. 파비콘에는 글자를 넣지 않습니다.
- 일반 심벌의 기본색은 `#2563EB`. 어두운 배경에서는 역상 로고를 사용합니다. 파비콘의 파란 타일은 배경 모드와 무관하게 유지합니다.
- 웹폰트와 무관하게 동일하게 보이도록 Satoshi 900의 글자를 윤곽선으로 변환했습니다. [기존 서체의 공식 원본 CSS](https://api.fontshare.com/v2/css?f%5B%5D=satoshi%40700%2C900&display=swap)를 사용했습니다.
- 앱은 공통 `BrandLogo.jsx`를 통해 기존·모바일 헤더, 로그인 화면, 새 교실에 적용합니다. 글자 윤곽선은 `brand-wordmark.js`에 있고 심벌과 내보내기 원본은 SVG입니다.
- 미리보기는 개발 서버의 `/brand-preview.html`입니다. 정식 앱의 새 메뉴나 배포 진입점으로 추가하지 않았습니다.

## 확인

기존·새 교실 빌드 성공, 기존 프론트 회귀 252개 통과, lint 오류 0·기존 경고 6. SVG의 외부 폰트·스크립트 참조 없음, PNG 크기와 ICO 16·32·48px 포함을 확인했습니다. 16·24·32·48px 파비콘과 실제 교실 헤더의 밝은/어두운 테마를 시각 확인했습니다. 독립 검토에서 발견한 워드마크 하강부의 4유닛 잘림도 여백을 늘려 보정했습니다.

새 UI 동작이나 서버·수업 자료는 변경하지 않았고 운영 서비스에 배포하지 않았습니다. 브랜드 첫 시안이므로 후속 의견에 따라 형태·비율을 조정할 수 있습니다.
