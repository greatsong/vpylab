# VPyLab 교육 자료와 메뉴 정리

2026년 11월 6일. 기본 대상은 코딩을 처음 배우는 중·고등학생입니다. 기능을 체험하는 튜토리얼, 실력을 기르는 미션, 실제 작품을 보는 갤러리의 역할을 분리했습니다. 변경은 저장소에 반영했으며 이번 작업에서 운영 배포는 하지 않았습니다.

## 적용한 구성

| 입구 | 학습 목적 | 적용 내용 |
|---|---|---|
| 튜토리얼 | 서비스의 강점을 짧게 체험 | 3D, 빛과 소리, 움직임, 버튼의 4개 체험. 각각 3~5분 예상, 10줄 이내 제공 코드, 한 가지 변경과 관찰 질문. 점수·필수 진도 없음 |
| 미션 | 작은 작품을 만드는 단계별 훈련 | 빛과 소리 기초 8차시 → 선택 핵심 연습 6단계 → 선택 저장·공유 4차시. 어느 단계도 잠그지 않음 |
| 갤러리 | 실제 작품에서 아이디어 얻기 | 사용자가 제공한 GlowScript 두 폴더의 33개 원본·출처·썸네일. 학생 작품은 앞에, 교사·참고 자료는 접어서 제공 |
| 만들기 | 자기 작품 제작 | 기존 에디터·프로젝트·저장 기능 유지. 체험·작품 코드를 열고 변경 가능 |

홈의 주 버튼은 첫 3D 체험으로 연결됩니다. 사용 안내·API 문서·소개·교사 대시보드는 보조 메뉴에 있습니다. 독립 코스 목록은 미션으로 통합하고, 학생 메뉴에서 예제 목록과 중복 교재 목록을 제거했습니다. 기존 코스·미션의 ID, 상세 링크, 코드, 학습 기록은 보존했습니다.

## 자료를 남기거나 기본 경로에서 뺀 이유

기존 자료에는 10개 코스의 65개 차시와 54개 미션이 있습니다. 모두를 같은 비중으로 제시하면 입문자가 순서와 필수 범위를 판단해야 합니다. 기존 교육 검토 문서와 현재 시작 코드·목표·검사 기준을 대조해 다음처럼 편성했습니다. 학습 효과를 실측한 순위는 아닙니다.

- **빛과 소리 기초 교재 유지:** 작은 코드부터 시작하고 예상·실행·변경·제작·확인을 연결합니다. 중복되는 구 입문 코스를 새 기본 목록에 다시 나열하지 않습니다.
- **핵심 연습은 6개로 선별:** `CT-6` 변수 → `CT-7` 반복 → `CT-13` 조건 → `CT-11` 리스트 → `SN-1` 빛과 소리 결합 → `CR-1` 내 캐릭터. 기존 문제 ID를 유지해 이전 기록과 연결합니다.
- **이해 확인 질문 추가:** 조건문은 59와 60에서 비교하고, 반복문은 개수를 바꾼 뒤 마지막 좌표를 예상하며, 캐릭터는 특징과 코드를 연결해 설명합니다. 자동 통과는 코드 조건 확인이며 이해·창의성의 확정 점수가 아닙니다.
- **저장·공유 과정은 선택:** 자기 작품을 만든 뒤 필요할 때 진행합니다. 첫 체험에 계정 연결 절차를 넣지 않습니다.
- **기존 나머지 미션·융합·심화 교재는 기본 경로에서 제외:** 함수·복합 상태·삼각함수·물리 모델을 첫 경험에서 동시에 요구하지 않습니다. 자료와 직접 링크는 유지해 수업별로 선택할 수 있습니다.
- **갤러리 작품은 필수 과제로 바꾸지 않음:** 완성 작품 감상과 작은 코드 실험에 사용합니다. 긴 게임·시뮬레이션 전체 구현을 입문 성취 기준으로 두지 않습니다.

기본 기초 과정의 8차시와 후속 연습 6단계는 서로 다른 선택지입니다. 6단계를 추가 필수 6차시로 계산하지 않습니다.

## GlowScript 원본 33개

출처는 [2024 프로젝트 모음](https://glowscript.org/#/user/greatsong21/folder/2024vpython%ED%94%84%EB%A1%9C%EC%A0%9D%ED%8A%B8%EB%AA%A8%EC%9D%8C/) 27개와 [2021 서울고 작품 모음](https://glowscript.org/#/user/greatsong21/folder/2021%EC%84%9C%EC%9A%B8%EA%B3%A0%EC%9E%91%ED%92%88%EB%AA%A8%EC%9D%8C/) 6개입니다. 원본 코드를 수정하지 않고 별도로 보존하고, SHA-256으로 보존 여부를 검사합니다.

2021 모음의 6개와 2024 모음의 `2018한성과학고스윙바이`를 학생 관련 작품 7개로 배치했습니다. `5유튜브실험재현`은 원문에 학생 작품 변형이라고 적혀 있어 **학생 원작·교사 변형**으로 표시했습니다. 나머지 26개는 교사·참고 자료입니다. 제목의 교사 이름·선생님·연수 표기를 학생 저작으로 바꾸지 않았습니다. 원본 이름과 출처는 작품 상세에서 확인할 수 있습니다.

Python API 검사에서는 GlowScript 버전 선언만 제거하고 `from vpython import *`를 추가했습니다. 300회 rate 호출 제한 안에서 Python 오류가 없는지 확인했으며, 계속 실행되는 작품이 제한으로 멈춘 것은 정상적인 검사 중단으로 구분했습니다.

- 27개: Python API 실행 확인. VPyLab에서 코드를 열어 실험 가능. 전체 게임 조작·외부 이미지·화면의 완전한 동일성까지 검증한 것은 아닙니다.
- 4개: 호환 보완이 필요해 원본 실행·원본 코드만 제공.
- 2개: `240529ns01`, `240710-6`는 실질 내용이 없어 원본 기록만 보존.

호환 보완 4개는 `경사하강법-학습률실습(solsol)`의 정수 범위 인자, `군집화알고리즘(solsol)`의 구문, `2023연수작품(과학선생님)`의 미정의 `speed_f`, `2023연수작품테트리스(수학선생님)`의 실수 리스트 인덱스 문제입니다. 원본을 자동으로 고쳐 저작 의도를 바꾸지 않았습니다.

새로운 VPyLab 공개 작품은 확인된 ID만 학생 전시에 포함하는 구조입니다. 기존 DB 작품과 작성자의 내 작업 접근·공개 상태는 바꾸지 않았습니다.

## Claude 토론에서 채택한 것

`3-way` 브리지로 Claude와 두 차례 교육 구성만 토론했습니다. 자동 승인 검토가 비공개 코드·교육자료 사본의 외부 전달을 거부해 파일은 공유하지 않았습니다. Claude가 구체적인 코드를 검토했다고 주장하지 않습니다.

짧은 무점수 체험, 문제집 입구 통합, 학습 기록 보존, 자동 확인과 이해 평가 구분, 빈 갤러리를 예제로 위장하지 않는 원칙을 채택했습니다. 재검토에서는 조건을 리스트보다 앞에 두고, 이어 하기와 추천 경로를 제공하자는 의견을 반영했습니다.

Claude가 제안한 별도 ‘내 학습’ 메뉴와 튜토리얼 4개 전체 이수 권장은 채택하지 않았습니다. 저장한 작업은 만들기 화면에서 접근하고, 튜토리얼은 원하는 것부터 선택하도록 했습니다. 기초 8차시와 후속 연습 6단계를 하나의 필수 차시표로 합치자는 제안도 적용하지 않았습니다.

## 검증

- 프론트엔드 회귀 테스트: 50개 파일, 629개 테스트 통과.
- Vite 배포 빌드 통과. 기존 대용량 청크와 동적 import 경고는 남아 있습니다.
- 새 페이지·자료 모듈 ESLint 통과, `git diff --check` 통과.
- 브라우저 화면: 320·390·1440px × 7개 화면, 총 21개 검사 통과. 가로 넘침 없음.
- 실제 Chromium·Pyodide·Three.js: 4개 튜토리얼, 라이언 참고작, 다중 공 학생 작품의 총 6개 실행 통과. 버튼 클릭, 움직임, 객체 수 확인.
- 33개 원본의 파일·출처·해시·썸네일 연결 확인. 33개 전부의 실제 게임 플레이나 원본 GlowScript 동작을 검증한 결과는 아닙니다.

주요 변경 파일은 `client/src/components/layout/Header.jsx`, `client/src/pages/{Home,Tutorials,Missions,Courses,Gallery,SourceProject,MissionPlay,Sandbox}.jsx`, `client/src/data/{tutorials,training,glowscript-projects,student-projects}.js`이며, 원본은 `client/public/projects/glowscript/`에 있습니다. 기존 미커밋 변경은 보존했습니다.

## 사용자 판단이 필요한 것

1. **2024 모음의 학생 작품 추가 분류:** 현재 학생 관련 7개, 교사·참고 26개입니다. 날짜·코드만 있는 프로젝트의 실제 작성자를 알면 분류를 바꿀 수 있습니다. 현재는 모호한 작품을 학생 작품이라고 표시하지 않습니다.
2. **호환 보완 4개의 처리:** 원본 링크만 유지할지, 원본을 보존하면서 VPyLab용 수정본을 만들지 선택할 수 있습니다. 학생 입문 경로에서는 현재 제외했습니다.

기존 자료의 영구 삭제나 학습 기록 초기화는 필요하지 않아 수행하지 않았습니다.
