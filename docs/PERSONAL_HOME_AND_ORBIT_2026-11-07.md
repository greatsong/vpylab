# 내 메인과 첫 화면 3D 회전 — 2026-11-07

## 사용 흐름

만들기 → 도구 → **현재 프로젝트를 내 메인으로 설정**에서 이름을 입력하면 홈으로 이동합니다. 저장된 프로젝트뿐 아니라 지금 편집 중인 코드도 사본으로 사용할 수 있습니다. 현재 코드가 실제 실행한 코드와 같을 때만 화면을 썸네일로 캡처합니다. 코드가 바뀌었으면 이전 실행 화면을 잘못 썸네일로 쓰지 않습니다.

홈의 **내 메인 꾸미기**는 환영 문구·배경색과 작품 표시 여부를 바꿉니다. **내 작품 실행**을 눌러 실제 코드를 실행하고 3D 장면을 돌려봅니다. **코드 수정**은 별도 사본을 열고 활성 원본 프로젝트 컨텍스트를 해제해 원본 저장 대상으로 오해하지 않게 합니다. 수정 후 같은 버튼으로 다시 설정하면 갱신됩니다.

기본 화면으로 돌아가기는 표시만 기본으로 바꾸고 코드 사본을 보존합니다. 다시 꾸미기에서 작품 표시를 켜서 복구합니다. 새 작품을 지정하면 메인 사본은 교체됩니다. 중요한 원본은 프로젝트에 저장해야 합니다.

설정은 브라우저 localStorage에 계정 ID별로 보관하고 손님 슬롯을 구분합니다. 다른 기기로 자동 동기화하지 않으며 공개·갤러리 등록과 무관합니다. 서버 API·DB 스키마·공개 권한을 바꾸지 않았습니다.

## 회전

기본 환영 친구·프렌즈에 OrbitControls를 연결했습니다. 드래그로 회전하고 시점 초기화로 처음 각도로 돌아갑니다. 모션이 끝난 뒤에도 controls의 change 이벤트로 렌더링합니다. damping과 줌·팬을 끄고 터치 pan-y를 유지해 홈 세로 스크롤을 막지 않습니다. 선택한 친구가 바뀌면 처음 시점으로 돌아옵니다. 개인 작품은 기존 Viewport3D의 회전·확대·전체 화면을 사용합니다.

## 실행·데이터 처리

- 작품은 포스터로 시작하며 실행을 눌러야 Python/Worker를 준비합니다. 원시 HTML이나 iframe으로 코드를 실행하지 않습니다.
- 기존 Worker의 API 제한과 무응답 정지 처리를 재사용합니다. 컴포넌트 구독이 마지막으로 해제되면 실제 Worker가 종료되고 소리를 정리합니다.
- 출력은 최근 8개/각 1,000자만 표시합니다. 오류와 메시지는 React 텍스트로 표시합니다.
- 코드 50,000 UTF-8 바이트, 래스터 썸네일 250,000자, 설정 JSON 400,000자로 제한합니다. 썸네일은 PNG/JPEG/WebP base64만 허용하며 SVG·외부 주소를 쓰지 않습니다. 배경은 검증한 HEX 값만 사용합니다.
- 인증 로딩 중에는 손님/개인 작품을 보여주지 않고, 계정 전환 시 이전 슬롯을 즉시 숨깁니다. 설정 대화상자에서 계정이 바뀌면 저장을 거부합니다. 같은 탭·다른 탭의 설정 변경을 반영합니다.
- 저장 불가·용량 초과는 실패로 알리고 기존 사본을 보존합니다. lazy import 또는 WebGL 실패는 작품 영역의 오류 경계로 처리해 설정과 기본 복구를 계속 사용할 수 있습니다.

## 검증

- 개인 메인 관련 단위 검사 14개: 소유자/손님 분리, 계정 전환, 인증 준비 중 노출 방지, 사본 보존, 큰 코드·잘못된 썸네일·저장 실패 처리, 같은 탭/다른 탭 갱신.
- 전체 클라이언트 76개 파일/819개 검사 통과. 린트 오류 0개(기존 LoadingScreen 경고 1개), 빌드 성공.
- 실제 게스트 UI에서 지정·새로고침·실제 Pyodide 실행·개인 작품/기본 친구 회전·카메라 초기화·편집 사본·모바일·복구·Worker 종료를 검증합니다. 계정별 분리는 단위 검사이며 실제 계정 로그인 검증으로 주장하지 않습니다. DB 쓰기는 하지 않습니다.
- 기본 환영 화면의 모션·반응형·모션 감소·WebGL 대체 화면 등 기존 17개 브라우저 검사 통과.

준비 실패 재시도·오류 노출, 인증 준비 placeholder, 보관 총량 제한·손님 안내·명시적 삭제, 정상 본문 종료와 소리 정지 구분, 대화상자 CSS 직접 로드, 사본 제목의 잔존 방지, 썸네일 선검증·빈 코드 오류 분리, 초기화 시 코드 보존, 기본 환영 문구 유지 등 9개 지적을 검토해 반영했습니다. Viewport3D·썸네일·인증 구현도 확인하고 실제 브라우저에서 회전·사본 편집·복구를 검증했습니다.
