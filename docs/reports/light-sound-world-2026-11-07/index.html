Patatap — 키 하나로 소리와 움직이는 모양을 함께 연주하기

코드 읽기 전에 “입력 → 반응”을 몸으로 경험하는 5분 활동

공식 소개를 한국어로 풀면, 손가락 입력으로 소리와 움직이는 도형을 함께 만드는 작은 연주 도구입니다. 페이지의 주인공은 긴 설명이 아니라 즉시 반응하는 화면입니다. 사용자는 무엇을 눌렀는지와 어떤 결과가 나왔는지를 연결하고, 여러 입력을 순서와 간격으로 묶어 자기 패턴을 만듭니다. 이 과정은 이벤트, 순서, 반복을 배우는 출발점으로 해석할 수 있습니다. 다만 Patatap 자체가 Python 교육용 코드 편집기는 아닙니다. 여기서는 먼저 반응을 체험하고, 아래 실습에서 같은 구조를 코드로 다시 만드는 다리 역할로 사용합니다. 공식 페이지는 웹 2D 그리기 API인 Two.js로 제작되었다고 밝힙니다. 이 도구의 교육적 가치는 복잡한 3D 기술이 아니라 아주 적은 조작으로 완성도 있는 결과를 들려주고 보여준다는 점에 있습니다.

02

p5.js + p5.sound — 소리의 원리를 화면에서 보고 직접 고치기

마우스 좌표를 소리와 도형의 값으로 바꾸는 JavaScript 실습

p5.js는 화면에 도형을 그리며 프로그래밍을 배우기 좋은 JavaScript 환경이고, p5.sound는 소리 합성·재생·분석 도구를 더합니다. 공식 Amplitude Modulation 예제는 들리는 진동인 캐리어와 그 음량을 조절하는 모듈레이터를 나누어 보여줍니다. 여기서 한국어로 해석해야 할 핵심은 “소리 자체의 높이를 바꾸는 일”과 “소리의 크기를 주기적으로 흔드는 일”이 다르다는 것입니다. 공식 예제의 마우스 가로 위치는 모듈레이터의 진폭, 세로 위치는 모듈레이터의 주파수에 연결됩니다. 화면의 파형을 같이 보면서 어느 입력이 무엇을 바꾸는지 탐구합니다. 모든 코드를 처음부터 설명하기보다는 완성작을 실행하고 숫자 하나를 바꾼 뒤, 관찰을 근거로 역할을 추론하게 하는 편이 적절합니다. 아래 별도 코드는 공식 작품의 복제가 아니라 같은 API 개념으로 만든 작은 원형 악기입니다.

핵심 개념을 한국어로 읽기

Oscillator·오실레이터
주기적으로 변하는 신호를 만드는 도구입니다. 들을 수 있는 주파수로 출력하면 기본 음원이 되고, 느린 신호로 다른 음의 크기를 조절하면 제어 신호가 됩니다.
Amplitude modulation·진폭 변조
한 신호가 다른 소리의 크기를 움직이게 합니다. 느린 변화는 떨림이나 리듬처럼 느껴질 수 있습니다. 모듈레이터 주파수와 캐리어 주파수를 혼동하지 않도록 비교합니다.
Amplitude analysis·음량 분석
p5.Amplitude는 순간의 진폭 수준을 읽습니다. 이 값을 원 크기나 밝기에 연결하면 오디오 반응형 화면을 만들 수 있습니다. 진폭 값 하나가 음 이름을 뜻하는 것은 아닙니다.
Mapping·범위 변환
화면의 가로 좌표 0~폭을 주파수 220~660Hz 같은 다른 범위로 바꾸는 일입니다. 입력과 출력 범위를 먼저 예상하고 극단값을 시험합니다.

관찰할 차이

보기 좋은 장면을 넘어 “이 규칙이면 어떤 운동이 생길까?”를 묻는 학습

Web VPython은 브라우저에서 3D 애니메이션과 벡터 연산을 사용하는 환경입니다. 기본 조명·카메라·마우스 조작을 준비해 주므로, 학생은 물체를 만들고 위치를 바꾸는 규칙에 집중할 수 있습니다. 공식 공유 안내는 공개 폴더의 작품을 로그인 없이 실행하고 소스를 볼 수 있다고 설명합니다. 반면 자신의 프로그램을 만들고 클라우드에 보관하는 과정에는 로그인이 필요합니다. 교육적으로는 완성된 모델을 감상하는 것보다 초기값 하나를 바꾸고, 같은 시간 간격으로 계산한 결과를 비교하는 일이 중요합니다. Bounce에서 반복과 충돌 조건을, BinaryStar에서 두 물체의 상호작용을, AtomicSolid에서 많은 물체의 연결을 순차적으로 살펴볼 수 있습니다. 이 예제들은 3D 과학 모델의 참고 자료이며 소리 교육 콘텐츠로 확인된 것은 아닙니다. Strudel — 짧은 패턴 문장을 바꾸며 실시간으로 연주하기

반복·쉼·겹침을 한 줄에 적고, 지금 울리는 부분을 눈으로 확인합니다.

Strudel은 브라우저에서 패턴을 작성하고 실행 중에도 바꾸는 라이브 코딩 환경입니다. 문법은 Python이 아니라 JavaScript 기반의 함수와 Tidal 계열 mini-notation을 사용합니다. 첫 수업에서는 복잡한 음악 이론보다 문자열 안의 소리 순서, 쉼, 반복을 바꾸는 경험부터 시작할 수 있습니다. 공식 워크숍의 코드 칸 자체가 실행 가능한 편집기라 설명 페이지에서 곧바로 실습할 수 있다는 점이 특히 좋습니다. 다만 한 cycle 안에 적힌 항목을 나누어 배치하므로, 항목을 하나 더 넣으면 단순히 곡이 길어지기보다 같은 구간에 더 많은 소리가 들어갈 수 있습니다. Python의 리스트 반복과 완전히 같은 시간 의미로 설명하지 않아야 합니다.
